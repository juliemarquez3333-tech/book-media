# Amazon Attribution links (updated Nov 6, 2026 – full export, 139 tags)

- **links_by_book_and_platform.csv** – USE THIS ONE. One tracked URL per book per platform (Pinterest, Facebook, YouTube, Instagram, TikTok, Kit, RedCaseFile.com), looked up by ASIN. Every book has all five social platforms.
- amazon_attribution_tags.csv – the raw Amazon Attribution export it was built from (campaign names vary, e.g. "Cozy Xmas Spaces– Pinterest" = Vol 1, "Cozy Xmas Critters– Pinterest").

Rule for all content: whenever a post, pin, email or web page links to an Amazon book, use the tracked URL for that book AND that platform, never a plain amazon.com/dp/ link.
- Critters links point to the paperback; the hardcover (B0HQJP3HRY) is a tracked product in the same campaigns, so its sales count too.
- Cozy Winter Spaces links point to the paperback (B0HQFWCR3V).
- Christmas Mini Mysteries has separate paperback (B0HLB57PF1) and Kindle (B0GX2ZCBM4) tags; use the paperback for gift posts.
- Rows marked DO NOT USE are excluded. Instagram and TikTok captions can't hold links: those platforms are tracked through the link-in-bio pages.
