# Amazon Attribution links (updated Nov 5, 2026)

amazon_attribution_tags.csv lists every tag: campaign, publisher (Pinterest, Instagram, TikTok, Facebook, YouTube, Kit, RedCaseFile.com) and the tracked URL in the "Attribution tags" column.

Rule for all content: whenever a post, pin, email or web page links to an Amazon book, use the tracked URL for that book AND that platform from this file, never a plain amazon.com/dp/ link. If no tag exists for that book + platform, use the plain link and note it so a tag can be created.
Instagram and TikTok captions can't hold links: those platforms are tracked through the link-in-bio pages.
